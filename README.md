# Revenue Metrics Analysis

## Project Overview

This project analyzes revenue and customer metrics for a subscription-based product using SQL and Tableau.

The analysis focuses on revenue dynamics, paid user growth, churn, ARPPU, and customer lifetime value.

## Tools

- SQL
- Tableau

## Key Metrics

- Monthly Recurring Revenue (MRR)
- Paid Users
- New MRR
- Expansion MRR
- Contraction MRR
- Churned Revenue
- New Paid Users
- Churned Users
- User Churn Rate
- ARPPU (Average Revenue Per Paying User)
- Customer Lifetime Value (LTV)

## Analysis

The project includes:

- Monthly revenue and paid user analysis
- Revenue drivers analysis
- New, expansion, contraction, and churned revenue analysis
- Paid user growth and churn analysis
- Monthly user churn rate analysis
- ARPPU trend analysis
- Customer lifetime value analysis

## Dashboard

The Tableau dashboard provides an interactive overview of the main revenue and customer metrics and allows filtering by:

- Payment Month
- Language
- Age
- Game Name

## Project Files

- `Revenue_Metrics_Analysis.twbx` — Tableau workbook
- `Revenue_Metrics_Dashboard.png` — dashboard preview
- `revenue_metrics_analysis.sql` — SQL queries used for data preparation and analysis
